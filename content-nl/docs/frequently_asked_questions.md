Antwoorden op veelgestelde vragen over de site, de documentatie en
ondersteuning. Kies een vraag om het antwoord te tonen.

## Algemene vragen

{{< faq question="Wat is Homelab-Alpha.nl?" >}}
Homelab-Alpha.nl is een website over het ontdekken van en experimenteren met
allerlei technische opstellingen en projecten in een homelab. Het is een plek
voor techliefhebbers om te leren, kennis te delen en inspiratie op te doen bij
verschillende homelabprojecten.
{{< /faq >}}

{{< faq question="Wie zit er achter Homelab-Alpha.nl?" >}}
Homelab-Alpha.nl wordt gemaakt door GJS, een techliefhebber die graag aan
homelabopstellingen sleutelt en kennis deelt met de community. GJS ontdekt graag
nieuwe technologie en helpt anderen het beste uit hun homelab te halen.
{{< /faq >}}

## De website gebruiken

{{< faq question="Hoe navigeer ik door de website?" >}}
Met het menu aan de linkerkant van elke pagina navigeer je eenvoudig door de
website. Klik op de categorie of sectie die je interesseert om de inhoud te
bekijken. De site is gemaakt om gebruiksvriendelijk en intuïtief te zijn.
{{< /faq >}}

{{< faq question="Werkt de website goed op een mobiel apparaat?" >}}
Ja, Homelab-Alpha.nl is geschikt gemaakt voor mobiele apparaten. Of je nu een
smartphone of een tablet gebruikt, de site werkt soepel.
{{< /faq >}}

## Documentatie

{{< faq question="Welke documentatie staat er op de site?" >}}
De sectie "docs" bevat uitgebreide documentatie, tutorials en handleidingen. Je
vindt er informatie over allerlei homelabprojecten, tools en technologieën. Het
is een handige bron voor zowel beginners als gevorderden.
{{< /faq >}}

{{< faq question="Komt de informatie van een taalmodel?" >}}
Ja, een deel van de documentatie is geschreven met hulp van Claude, een
AI-assistent van Anthropic. Als Claude heeft bijgedragen, staat dat duidelijk
bovenaan de pagina. Bijdragen volgen het AI-beleid voor bijdragen van de
repository, en de inhoud wordt nagekeken voordat die wordt gepubliceerd. Toch is
het verstandig om de informatie te controleren voordat je erop vertrouwt. De
Nederlandse vertaling is ook gemaakt met hulp van Claude.
{{< /faq >}}

{{< faq question="Kan ik bijdragen aan de documentatie?" >}}
Ja. Bijdragen zijn welkom in alle repository's van Homelab-Alpha, ook in de bron
van deze site. Kairos is de uitzondering: dat neemt pas bijdragen aan vanaf
release v1.0.0. Lees eerst de
[richtlijnen voor bijdragen](/contributing/contribute/). Daarin staan de namen
van branches, de commitberichten en het reviewproces.
{{< /faq >}}

{{< faq question="Welke licentie geldt voor de inhoud?" >}}
De inhoud valt onder de Creative Commons
Naamsvermelding-NietCommercieel-GelijkDelen 4.0 Internationaal-licentie (CC
BY-NC-SA 4.0). Zie de pagina [licentie](/license/) voor de volledige tekst.
Kairos is de uitzondering: dat valt onder de Apache License 2.0.
{{< /faq >}}

{{< faq question="Waar vind ik de bron van de scripts en configuratiebestanden?" >}}
Elk project heeft een eigen repository op
[GitHub](https://github.com/homelab-alpha): AdGuard Home, Docker, dotfiles,
Kairos, OpenSSL en Shell Script. De documentatiepagina's tonen en leggen de
bestanden uit die repository's uit.
{{< /faq >}}

## Ondersteuning

{{< faq question="Hoe krijg ik hulp bij een project of probleem?" >}}
Homelab-Alpha biedt geen directe ondersteuning. Stel je vraag in de categorie
Help & Support van de GitHub Discussions van de betreffende repository. Gebruik
GitHub Issues voor bugmeldingen, niet voor algemene vragen.
{{< /faq >}}

{{< faq question="Is er een forum of discussieplatform?" >}}
Er is geen forum op de website. Gebruik de GitHub Discussions van de repository
waar je vraag over gaat. Voor problemen met de documentatie gebruik je de
discussies van de docs-repository van Homelab-Alpha.
{{< /faq >}}

{{< faq question="Hoe meld ik een beveiligingslek?" >}}
Meld het niet in een openbaar issue. Gebruik de privé GitHub Security Advisory
van de repository, zoals beschreven in het beveiligingsbeleid.
{{< /faq >}}

## Overig

{{< faq question="Mag ik inhoud van Homelab-Alpha.nl delen op sociale media?" >}}
Zeker! Deel gerust alles wat je interessant of waardevol vindt op je sociale
media. Delen is lief!
{{< /faq >}}

{{< faq question="Hoe vaak wordt de website bijgewerkt?" >}}
De website wordt regelmatig bijgewerkt met nieuwe inhoud, tutorials en
documentatie. Kom dus geregeld terug om op de hoogte te blijven van de nieuwste
informatie en projecten.
{{< /faq >}}
