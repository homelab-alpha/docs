## General Questions

**What is Homelab-Alpha.nl?**\
Homelab-Alpha.nl is a website dedicated to exploring and experimenting with
various technology setups and projects within a home laboratory environment.
It's a place for tech enthusiasts to learn, share, and get inspired by different
home lab projects.

**Who is behind Homelab-Alpha.nl?**\
Homelab-Alpha.nl is run by GJS, a tech enthusiast passionate about tinkering
with homelab setups and sharing knowledge with the community. GJS loves
discovering new technologies and helping others make the most of their home
labs.

<br />

## Website Usage

**How do I navigate the website?**\
Navigating the website is easy with the menu on the left side of each page. Just
click on the category or section you're interested in to explore its contents.
It's designed to be user-friendly and intuitive.

**Is the website mobile-friendly?**\
Yes, Homelab-Alpha.nl is optimized for mobile devices. Whether you're using a
smartphone or a tablet, you can enjoy a seamless browsing experience.

## Documentation

**What type of documentation is available on the site?**\
The "docs" section contains comprehensive documentation, tutorials, and guides.
You'll find a range of information related to various home lab projects, tools,
and technologies. It's a great resource for both beginners and advanced users.

**Is the information derived from a language model?**\
Yes, some of the documentation is written with the help of Claude, an AI
assistant developed by Anthropic. Whenever Claude has contributed, it is clearly
indicated at the top of the page. Contributions follow the AI contribution
policy of the repository, and the content is reviewed before it is published.
Even so, it is advisable to verify the information before you rely on it.

**Can I contribute to the documentation?**\
Yes. Contributions are welcome in all Homelab-Alpha repositories, including the
source of this site. Read the [contributing guidelines] first. They describe the
branch names, the commit messages, and the review process.

**Which license applies to the content?**\
The content is licensed under the Creative Commons
Attribution-NonCommercial-ShareAlike 4.0 International License (CC BY-NC-SA
4.0). See the [license] page for the full text.

**Where can I find the source of the scripts and configuration files?**\
Every project has its own repository on [GitHub]: AdGuard Home, Docker,
dotfiles, OpenSSL, and Shell Script. The documentation pages show and explain
the files from those repositories.

## Support

**How can I receive assistance for a specific project or issue?**\
Homelab-Alpha does not offer direct support. Ask your question in the Help &
Support category of the GitHub Discussions of the relevant repository. Use
GitHub Issues for bug reports, not for general questions.

**Is there a community forum or discussion board available?**\
There is no forum on the website. Use the GitHub Discussions of the repository
that your question is about. For problems with the documentation, use the
discussions of the Homelab-Alpha docs repository.

**How do I report a security vulnerability?**\
Do not report it in a public issue. Use the private GitHub Security Advisory of
the repository, as described in its security policy.
